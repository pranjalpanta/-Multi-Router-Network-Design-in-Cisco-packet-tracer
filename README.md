# 🌐 Multi-Router Network Design in Cisco Packet Tracer

## 📌 Project Overview

This project demonstrates the design and implementation of a multi-city enterprise network using Cisco Packet Tracer. The network connects five different locations through routers and switches while providing reliable communication between remote LANs using static routing.

The project focuses on building a scalable and organized network infrastructure similar to a real-world enterprise WAN.

---

## 🚀 Technologies Used

- Cisco Packet Tracer
- Cisco Routers
- Cisco Switches
- FastEthernet & Serial Connections
- IPv4 Addressing
- Static Routing
- RIP (configured but static routes used for routing)
- LAN & WAN Design

---

## ✨ Features

- 🌍 Five interconnected city networks
- 🔀 Multi-router WAN topology
- 🌐 IPv4 addressing and subnetting
- 📡 FastEthernet and Serial interfaces
- 🛣 Static route configuration for inter-network communication
- 🔁 RIP routing process configured
- 🔌 Switch-based LAN connectivity
- 📶 End-to-end connectivity between remote sites

---

## 🛠 Network Configuration

### Router Configuration

- Configured multiple FastEthernet interfaces
- Configured Serial WAN interfaces
- Assigned IPv4 addresses to every network
- Configured clock rate on DCE serial links
- Implemented static routing
- Enabled RIP routing process
- IP Classless enabled

### Switch Configuration

- Basic switch configuration
- Hostname configuration
- Domain name configuration
- PVST Spanning Tree enabled
